# MEA Review design tradeoffs

| Choice | What it costs | Evidence |
| --- | --- | --- |
| Reserve request, token and estimated USD capacity before dispatch. Make one attempt per provider request and retain reservations when the result is uncertain. | Some transient errors end useful tasks. An operator must account for spending across stores. | [Provider configuration](OPERATING_GUIDE.md#run-the-controlled-real-deepseek-lane), [spending ledger](../mea/investigation/spending.py), [live runner](../mea/investigation/live_run.py) |
| Require each candidate to anchor to a changed line and cite evidence the model was shown. Reject unsupported inputs and undeclared tool calls. | Plausible findings can be suppressed when required lines are unavailable. Source-backed validation leaves semantic correctness to a human. | [Candidate validation](../mea/investigation/validation.py), [bounded tool view](../mea/investigation/provider_view.py) |
| Bind each approval to the exact target, head, anchor and body. Persist a send intent and its duplicate slot before dispatch, then reconcile uncertainty with a read-only listing. | Stale approvals need another preview. An unresolved slot can hold up a comment. A later increment may leave an outdated anchor or unknown file lineage. | [Publisher](../mea/human_review/publisher.py), [re-review](../mea/human_review/rereview.py), [writeback operating guide](OPERATING_GUIDE.md#send-confirmed-line-comments-attended-allowlisted) |
| Pin source revisions and freeze the holdout, baseline, scoring and stop rule before evaluation. Keep licensed examples and aggregates in Git. | Snapshots capture a bounded view. New head revisions need new captures. Private holdout rows and provider responses require authorized storage for reproduction. | [Capture reader](../mea/github_input.py), [benchmark method](../benchmarks/reviewbench/v4/README.md), [source manifest](../SOURCE-MANIFEST.tsv) |
| Freeze the negative benchmark result when the F1 gap falls below the preregistered threshold. Treat the novel-defect audit and anchor-visibility analysis as auxiliary. | The measured result supports human-reviewed candidates and leaves the cause of the misses open. Tuning further would require a fresh evaluation. | [Aggregate results](../benchmarks/reviewbench/v4/RESULTS.md), [auxiliary review](REVIEWBENCH_AUXILIARY.md) |
| Give MCP clients the same bounded view over one snapshot. Limit its capabilities to inventory and evidence retrieval. | A caller must collect and authorize a new snapshot separately. Resolution of dynamic targets and uncollected files stays unknown. | [Stdio server](../mea/mcp_server.py), [official SDK client check](../scripts/mcp-roundtrip.mjs) |
